# 家計簿アプリwebアプリ版

# 1.はじめに

より実務に近い環境での学習を目的として  
デスクトップアプリとして制作した家計簿アプリを  
Spring Bootを用いてwebアプリとして再構築しました。  　

## 公開URL

https://kakeiboweb.sol2424.com/

AWS EC2へデプロイ + Nginx + HTTPS化済み

# 2.機能一覧  

- 収入・支出の入力（項目・金額・日付）とリストの表示   
- データ編集/削除機能の追加
- フィルター機能を用いた合計表示機能
- グラフ表示機能  
- データ永続化（H2 Database）
- CSSを利用し背景画像を追加  
  - 使用画像：OKUMONO様より かわいい雲の柄背景　https://sozaino.site/archives/6411#google_vignette
 
# 3.工夫したこと 
- Spring Bootを用いてMVC構成（Controller / Service / Repository）を意識し、機能追加しやすい構造で開発しました。
- 収支データをカテゴリ別に管理し、一覧表示や編集・削除機能を実装することで実用性を高めました。
- 家計簿データはDB（H2）に保存し、アプリ再起動後もデータが保持されるようにしました。
- AWS EC2へデプロイし、外部からアクセス可能な環境を構築しました。
- systemdによる自動起動設定を行い、サーバー再起動後もアプリが継続動作するよう運用面も考慮しました。

# 5.おわりに

今回、Spring Boot を用いた家計簿Webアプリの開発に取り組みました。  
以前制作した JavaFX のデスクトップアプリと比較すると、Spring Boot は機能ごとの役割分担が整理されており、  
構造を意識しながら比較的スムーズに開発を進めることができました。 

今回のWebアプリ開発で改めて「データをどのように扱い、管理するか」 が非常に重要であることを実感しました。  
データベースとの連携や、画面表示とデータ処理の関係など、アプリの規模が大きくなるほど  
設計の難しさも増すことを学びました。  
また、機能追加を進める中で、より複雑なシステムを構築する難しさも経験できました。  
今後も新しい技術に積極的に触れながら、機能追加や改善を行うだけでなく、今回とは異なるジャンルのアプリ開発にも挑戦し、  
開発スキルの向上につなげていきたいと考えています。
