# 家計簿アプリwebアプリ版

# 1.はじめに

より実務に近い環境での学習を目的として

デスクトップアプリとして制作した家計簿アプリを

Spring Bootを用いてwebアプリとして再現しました。

## 使用技術   
***言語***
- Java SE17

***フレームワーク / UI***
- Spring Boot

***データベース***
- H2 Database

***フロント***
- HTML
- CSS
- Bootstrap

***グラフ***
- Chart.js

***開発環境/ツール***
- Eclipse
- Maven
